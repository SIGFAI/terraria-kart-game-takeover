# Kart Game Takeover

**Terraria** × Kart Game · visual · idea by the team

Bring Kart Game into the game in the most visible and funny way. The change shows in the first 30 seconds of play.

> I turned Terraria into a kart race: you drive a go-kart, goblin racers ram you, and a banana peel sends a zombie spinning.

## Install

Copy Sigf.tmod into Documents/My Games/Terraria/tModLoader/Mods, then enable "SIGF Mix" in tModLoader's Manage Mods menu. Start a world and you are already driving a kart.
